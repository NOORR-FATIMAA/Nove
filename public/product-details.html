Press-On Size & Fit Guide

How to measure

  1. Measure the width of each natural nail bed at its widest point, edge to edge.
  2. Compare each measurement to the closest size in the chart above — sizes typically run largest at the thumb (1) to smallest at the pinky (5).
  3. If you're between two sizes, size up and gently file the edge for a precise fit.
  4. Each Nove press-on set includes multiple sizes per nail position so you can custom-fit both hands.
